# Nwanyi Bu Ife Empowerment Humanitarian Foundation

A static frontend for the foundation, built with React, Vite, Tailwind CSS and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder, or connect the repository to Vercel. No backend is required.

## Replacing content

- Copy: `src/data/site.js`
- Photographs: `public/images/` (see `public/images/README.md`)
- Logo: `public/images/logo.png` and `public/favicon.png`

Contact details and the sponsorship WhatsApp link live in `src/data/site.js`.
